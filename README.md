### Висновок
У ході виконання практичної роботи було опановано основи роботи зі структурою даних «черга» (Queue) у середовищі C++/CLI Windows Forms з використанням оболонки .NET Framework та класу System::Collections::Generic::Queue<T>.

Під час роботи вивчено принцип організації даних FIFO («першим прийшов — першим пішов»), а також засвоєно практичне застосування основних методів та властивостей черги:
- Enqueue() — для додавання елементів у кінець черги;
- Dequeue() — для вилучення елементів з початку черги;
- Peek() — для перегляду першого елемента без його видалення;
- Count та Clear() — для контролю кількості елементів і повного очищення черги.

Окрім того, було реалізовано алгоритми обробки даних у черзі, зокрема обчислення середнього арифметичного значення парних чисел у заданому діапазоні та підрахунок загальної кількості символів у текстових рядках.
